# logistics-regression-telecom-churn
This project aims to predict customer churn for a leading telecom firm, focusing on high-value customers in the Indian and Southeast Asian markets.

I identified churners based on usage patterns, focusing on customers who have not made any calls or used mobile internet in the churn phase.
Customer Lifecycle Phases:

1.Good Phase: Normal service usage.
2.Action Phase: Issues or better offers from competitors.
3.Churn Phase: Service usage stops.

This project includes 
**Data Preparation:** Creating new features based on business understsanding, identifiyng high-value customer using 70th percentile of average recharge amount, tagging churners based on usages patterns. 
**Predictive Modeling:** I used PCA to handing large number of attributes, train various models to predict churn and identify important predictors, implement techniques to address class imbalance in churn prediction.
**Churn Prediction:** Predict high-risk churners to enable proactive retention strategies. Identify key variables that predict churn to understand customer behavior and improve services.
